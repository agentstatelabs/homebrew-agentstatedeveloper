# Homebrew Tap for AgentStateDeveloper

```sh
brew tap agentstatelabs/agentstatedeveloper
brew install asd
```

This installs three binaries — `asd` (CLI), `asd-mcp` (MCP stdio server), and `asd-serve` (HTTP server for the Lens).

Canonical source: <https://github.com/agentstatelabs/AgentStateDeveloper>.
Release artifacts: <https://github.com/agentstatelabs/agentstatedeveloper-releases/releases>.
